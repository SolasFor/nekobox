# NekoBox — SolasFor Edition

Персональный форк NekoBox 5.11.28.7 с обновлённым интерфейсом и удобным редактором маршрутизации приложений и доменов.

**[Релизы Windows x64](https://github.com/SolasFor/nekobox-pick-process/releases)** · [История сборок](https://github.com/SolasFor/nekobox-pick-process/actions) · [Сообщить об ошибке](https://github.com/SolasFor/nekobox-pick-process/issues)

Архивы portable собираются в GitHub Actions. Для обновления закройте приложение, сделайте резервную копию и распакуйте архив в папку программы, сохранив каталог `settings/`.

## Возможности этого форка

- Единое оформление светлой и тёмной темы: таблицы, вкладки, меню и диалоги.
- Наглядные строки правил с иконками приложений, подсветкой выбора и счётчиками.
- Выбор нескольких запущенных приложений с поиском по имени или пути.
- Поиск по существующим правилам приложений и доменов.
- Массовое назначение направления выбранным правилам.
- Методы доменных правил: `keyword` (по подстроке) и `suffix` (домен и поддомены).
- Отмена выбора исполняемого файла не создаёт пустое правило.
- Русский перевод новых элементов интерфейса.

## Настройка правил

1. Откройте нижнюю вкладку **Маршруты**.
2. В блоке **Приложения** выберите файл через **Добавить** или воспользуйтесь **Запущенные процессы…**.
3. В блоке **Домены** добавьте домен и выберите метод. Для `example.com` с методом `suffix` правило охватывает также `www.example.com`.
4. Укажите направление: `proxy`, `direct`, `block` или конкретный профиль.
5. Для нескольких строк используйте Ctrl/Shift и маркер выбора слева, затем **Направить выбранные…**. Поиск скрывает неподходящие строки, но не удаляет их.
6. Нажмите **Сохранить** и подтвердите перезапуск прокси, чтобы применить изменения.

Для приложений, не использующих системный прокси, включите режим TUN. Удаление выбранных строк доступно кнопкой **Удалить** или клавишей Delete, когда фокус находится в таблице.
